# Sound Effects

Place your sound effect files here:

- `spin.mp3` - Sound effect for when the wheel starts spinning
- `stop.mp3` - Sound effect for when the wheel stops

If you don't have sound files, the application will use Web Audio API to generate tones automatically.

## Recommended Sound Sources

- [Freesound.org](https://freesound.org/)
- [Zapsplat](https://www.zapsplat.com/)
- [Mixkit](https://mixkit.co/free-sound-effects/)

Make sure the files are in MP3 format for best browser compatibility.
